Must-Know Decision Rules

Access

  • Workforce SSO → IAM Identity Center.
  • External AWS account access → cross-account role.
  • Temporary scoped AWS CLI access → STS session.
  • Org-wide max permissions → SCP.
  • SCP cannot grant permissions.

Network

  • Many VPCs transitive routing → Transit Gateway.
  • Private service exposure to consumers → PrivateLink.
  • Hybrid DNS → Route 53 Resolver endpoints.
  • Instant global traffic shift → Global Accelerator / ARC.
  • Cache HTTP content globally → CloudFront.

Compute

  • <15 min event code → Lambda.
  • Long containers → ECS/Fargate.
  • GPU → EC2 GPU/EKS/SageMaker, not Lambda/Fargate.
  • Java cold starts → SnapStart or Provisioned Concurrency.
  • Near-zero inference traffic → SageMaker Serverless.

Data

  • Relational + joins → Aurora/RDS.
  • Key-value massive scale → DynamoDB.
  • Sub-ms cache/leaderboard → ElastiCache Redis.
  • SQL on S3 → Athena + Glue.
  • Warehouse BI → Redshift.

Migration

  • Server lift-and-shift → AWS MGN.
  • DB migration minimal downtime → DMS CDC.
  • Schema conversion → SCT.
  • NFS/SMB transfer → DataSync.
  • Network too slow → Snowball Edge.

Security

  • Threat detection → GuardDuty.
  • Vulnerability scanning → Inspector.
  • Sensitive S3 data discovery → Macie.
  • Security findings dashboard → Security Hub.
  • L7 SQLi/XSS → AWS WAF.

High-Frequency Traps

Do Not Confuse

  • Shield is not WAF.
  • Config is not GuardDuty.
  • Security Hub aggregates; it does not detect by itself.
  • CloudFront is CDN; Global Accelerator is anycast TCP/UDP acceleration.
  • EventBridge is routing; Kinesis is high-throughput streaming.

Limits That Eliminate Answers

  • Lambda max runtime: 15 minutes.
  • Step Functions Express max: 5 minutes.
  • SQS retention max: 14 days.
  • DynamoDB PITR: last 35 days.
  • CloudTrail delivery can take up to about 15 minutes.

RPO=0 Reality

  • Async replication is not strict RPO=0.
  • Aurora Global DB and DynamoDB Global Tables replicate asynchronously.
  • Strict zero loss usually needs app-level multi-region commit before acknowledgement.

Final 48-Hour Checklist

Memorize

  • Lambda 15 min; Express 5 min; Standard 1 year.
  • SQS retention 14 days; DynamoDB PITR 35 days.
  • SCP deny wins; SCPs do not grant permissions.
  • VPC peering is non-transitive.
  • CloudTrail delivery is not instant.

Practice Method

  • Read the last sentence first: it contains the requirement.
  • Underline constraints: no code change, lowest cost, least ops, RPO/RTO.
  • Eliminate impossible services by limits.
  • Choose AWS-managed over custom code when requirements match.

Do Not Do

  • Do not memorize fake dumps.
  • Do not choose complex custom solutions if managed service exists.
  • Do not ignore “no code changes”.
  • Do not pick async replication for strict RPO=0.
  • Do not overuse Lambda for long-running or GPU tasks.
