1) Ready-to-Book Threshold

You are exam-ready when:

  • Two timed mocks score 78%+.
  • No domain below 70%.
  • You can explain why each wrong option is wrong.
  • You finish 75 questions with 20+ minutes left for review.
  • You miss fewer than 5 questions due to AWS service confusion.

If mock score is 65–77%

  • Do not learn new random topics.
  • Review only missed domains and traps.
  • Redo questions by pattern, not by memorizing answers.
  • Delay exam if any high-weight domain is below 65%.

If mock score is <65%

  • Do not sit in 10 days unless unavoidable.
  • Focus on Organizations, Networking, DR, Migration, and Cost first.
  • Use decision tables daily until service selection is automatic.

4) High-Yield Decision Rules

Organizations / IAM

  • SCPs set maximum permissions; they do not grant access.
  • Explicit Deny always wins.
  • SCPs do not apply to the management account.
  • Workforce federation → IAM Identity Center.
  • External AWS account access → cross-account role.

Networking

  • Many VPCs + transitive routing → Transit Gateway.
  • Private consumer access to service → PrivateLink.
  • Hybrid DNS → Route 53 Resolver inbound/outbound endpoints.
  • Instant regional removal → Global Accelerator or Route 53 ARC, not normal DNS.
  • Static/dynamic HTTP acceleration → CloudFront.

Integration

  • High-throughput stream + replay → Kinesis Data Streams or MSK.
  • Event routing + SaaS integrations → EventBridge.
  • Worker decoupling + buffering → SQS.
  • Fanout → SNS to SQS queues.
  • Long workflows → Step Functions Standard, not Express.

Database

  • Relational + joins → Aurora/RDS.
  • Massive key-value scale → DynamoDB.
  • Sub-ms leaderboard/session cache → Redis.
  • SQL on S3 → Athena + Glue.
  • Warehouse analytics → Redshift.

Migration

  • Servers/VMs → MGN.
  • Database minimal downtime → DMS full load + CDC.
  • Engine/schema conversion → SCT.
  • NFS/SMB bulk transfer → DataSync.
  • Bandwidth cannot meet timeline → Snowball Edge.

Cost

  • Steady 24/7 compute → Savings Plans / RIs.
  • Interruptible stateless jobs → Spot.
  • Unknown S3 access → Intelligent-Tiering.
  • Known archive → lifecycle to Glacier/Deep Archive.
  • Private S3/DynamoDB from VPC → Gateway Endpoint to avoid NAT.

5) Red Flags That Cause Fails

Wrong Assumptions

  • Thinking SCPs grant permissions.
  • Choosing Route 53 when question says “instant” failover.
  • Using Lambda for >15-minute jobs.
  • Using Step Functions Express for long workflows.
  • Using DMS for every database target without checking support.

Ignoring Constraints

  • “No code changes” means do not replace MSMQ with SQS.
  • “Lowest operational overhead” favors managed services.
  • “Strict RPO=0” rules out normal async replication alone.
  • “Private connectivity” rules out public internet paths.
  • “Existing Windows SMB” points to FSx for Windows, not EFS.

Cost Mistakes

  • Buying RI/SP for short daily jobs.
  • Using NAT for heavy S3/DynamoDB traffic.
  • Keeping idle Redshift/EMR clusters running.
  • Moving private EC2 to public subnets to avoid NAT.
  • Using Intelligent-Tiering for billions of objects with predictable lifecycle.

6) Final Drill: 25 Rapid Questions

Answer mentally in under 15 seconds each. If you hesitate, review that topic.

1. Org-wide max permission boundary?
AnswerSCP. It limits; it does not grant.
2. Transitive routing between hundreds of VPCs?
AnswerTransit Gateway.
3. Private service access from consumer VPCs?
AnswerAWS PrivateLink.
4. VPC resolves on-prem DNS names?
AnswerRoute 53 Resolver outbound endpoint + forwarding rule.
5. On-prem resolves private hosted zone?
AnswerRoute 53 Resolver inbound endpoint.
6. 500K events/sec stream with replay?
AnswerKinesis Data Streams or MSK, depending on Kafka requirement.
7. Event routing from SaaS partner?
AnswerEventBridge.
8. Long-running workflow with human approval?
AnswerStep Functions Standard.
9. Java Lambda cold start, low traffic?
AnswerSnapStart first; Provisioned Concurrency if strict zero cold start is required.
10. GPU inference?
AnswerSageMaker or EC2/EKS GPU, not Lambda/Fargate.
11. Oracle to Aurora PostgreSQL?
AnswerSCT + DMS full load and CDC.
12. VM lift-and-shift to EC2?
AnswerAWS Application Migration Service (MGN).
13. NFS/SMB transfer to AWS over network?
AnswerAWS DataSync.
14. Petabytes with insufficient bandwidth?
AnswerSnowball Edge.
15. Windows SMB file share?
AnswerFSx for Windows File Server.
16. Linux shared NFS file system?
AnswerAmazon EFS.
17. SQL on S3 logs?
AnswerAthena + Glue Data Catalog.
18. Immutable audit log retention?
AnswerCloudTrail organization trail + S3 Object Lock Compliance mode.
19. PII discovery in S3?
AnswerAmazon Macie.
20. CVE scanning for EC2/ECR?
AnswerAmazon Inspector.
21. Threat detection from CloudTrail/VPC/DNS logs?
AnswerGuardDuty.
22. Aggregate security findings?
AnswerSecurity Hub.
23. SQL injection protection?
AnswerAWS WAF, not Shield.
24. Private EC2 heavy traffic to S3?
AnswerS3 Gateway VPC Endpoint.
25. Strict RPO=0 across Regions?
AnswerApplication-level dual/multi-region commit before acknowledgement; native async replication alone is not strict RPO=0.
