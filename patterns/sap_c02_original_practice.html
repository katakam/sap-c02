1. A company needs temporary access to services blocked by an SCP during acquisition onboarding. What is the best approach?
  1. Add an IAM permission boundary to override the SCP.
  2. Create a temporary OU, attach the required Allow SCP, and move the account there.
  3. Add another Deny SCP at the child OU.
  4. Use the management account credentials in the acquired account.
Answer
B. SCPs define maximum permissions. Use OU placement for temporary guardrail differences. Permission boundaries cannot override SCPs.
Organizations / SCP
2. An API must run active-active across Regions and remove a Region immediately without DNS TTL delay. Which service is best?
  1. Route 53 latency routing
  2. AWS Global Accelerator
  3. CloudFront signed URLs
  4. Transit Gateway peering
Answer
B. Global Accelerator uses static anycast IPs and endpoint weights for fast traffic shifting. DNS-based failover can be delayed by caching/TTL.
Networking / HA
3. A workflow may wait for human approval and can run for several days. Which Step Functions workflow type should be used?
  1. Express workflow
  2. Standard workflow
  3. Lambda destination
  4. EventBridge Scheduler only
Answer
B. Standard workflows support long-running executions and callbacks. Express workflows are limited to short-duration workloads.
Step Functions
4. A Lambda function using Java has high cold-start latency but low, spiky traffic. The team wants minimal idle cost. What should they try first?
  1. Provisioned Concurrency for peak traffic all day
  2. Lambda SnapStart
  3. Move to EC2 Auto Scaling
  4. Increase SQS visibility timeout
Answer
B. SnapStart reduces Java cold starts without paying continuously for pre-warmed concurrency.
Lambda
5. EC2 instances in private subnets send high traffic to S3 through NAT Gateway. How can cost be reduced most directly?
  1. Move instances to public subnets
  2. Add an S3 Gateway VPC Endpoint
  3. Add more NAT Gateways
  4. Use AWS Site-to-Site VPN
Answer
B. Gateway endpoints for S3/DynamoDB keep traffic private and avoid NAT data processing charges.
VPC / Cost
6. A Kinesis stream has 40 shards, but only 4 shards receive most writes. What is the likely fix?
  1. Enable Enhanced Fan-Out
  2. Increase Lambda memory
  3. Use a higher-cardinality partition key
  4. Enable S3 lifecycle rules
Answer
C. Hot write shards usually come from low-cardinality partition keys. EFO improves read throughput, not write distribution.
Kinesis
7. A company needs immutable audit logs for 7 years across all AWS accounts. Which design is most appropriate?
  1. Per-account CloudTrail with local S3 buckets
  2. CloudTrail organization trail to S3 with Object Lock Compliance mode
  3. CloudWatch Logs with 7-day retention
  4. Config aggregator only
Answer
B. Organization trails centralize events. S3 Object Lock Compliance mode prevents deletion during retention.
Audit / Security
8. A Windows application requires SMB file shares and Active Directory integration with no code changes. Which storage service fits?
  1. Amazon EFS
  2. Amazon FSx for Windows File Server
  3. S3 Glacier Instant Retrieval
  4. Instance store
Answer
B. FSx for Windows supports SMB and AD integration. EFS is NFS-focused for Linux workloads.
Migration / Storage
9. A database migration from Oracle to Aurora PostgreSQL must minimize downtime and reduce license cost. Which tools are best?
  1. SCT for conversion and DMS full load + CDC
  2. Snowball only
  3. RDS read replica only
  4. CloudFront and Lambda@Edge
Answer
A. SCT helps convert schema/code. DMS full load + CDC keeps source and target synchronized until cutover.
Migration / Database
10. A workload runs 6 hours per day on EMR and remains idle the rest of the time. What is the best cost pattern?
  1. Buy 3-year RIs for all nodes
  2. Use transient EMR clusters and terminate after jobs
  3. Move all data to EBS io2
  4. Disable CloudTrail
Answer
B. Transient clusters avoid idle compute cost. Spot can further reduce cost for fault-tolerant task nodes.

11. A REST API requires API keys, usage plans, request validation, response caching, and WAF integration. Which API Gateway type is best?
  1. HTTP API
  2. REST API
  3. WebSocket API
  4. PrivateLink endpoint service only
Answer
B. REST APIs support these advanced API management features. HTTP APIs are cheaper but have fewer features.

  1. AWS Config organization rule with SSM Automation remediation
  2. Manual monthly review
  3. GuardDuty only
  4. CloudFront Origin Shield

13. A microservice sends malformed messages to SQS, and the DLQ keeps growing. What should be done first?
  1. Replay the DLQ immediately
  2. Increase visibility timeout only
  3. Fix consumer validation and quarantine invalid payloads
  4. Delete the DLQ
Answer
C. Fix the root cause first. Replaying before fixing the consumer sends bad messages back to the DLQ.

14. A global relational database requires cross-Region reads and RPO under 1 minute. Which option is most appropriate?
  1. Aurora Global Database
  2. S3 One Zone-IA
  3. DynamoDB DAX only
  4. CloudWatch Logs Insights
Answer
A. Aurora Global Database provides low-lag storage replication and secondary Region reads. It is not strict RPO=0.

16. A service needs strict ordering within customer workflows but high throughput across many customers. Which queue design is best?
  1. SQS Standard only
  2. SQS FIFO using customer ID as MessageGroupId
  3. One Lambda per customer
  4. CloudTrail Lake
Answer
B. FIFO preserves order within each message group. Multiple message groups allow parallelism across customers.

19. An application has hot DynamoDB writes for a small set of popular keys. Auto scaling is enabled but throttling continues. What should be changed?
  1. Use write sharding for hot keys
  2. Enable CloudFront OAC
  3. Use an SCP Allow list
  4. Increase CloudWatch retention
Answer
A. Table capacity does not remove per-partition limits. Write sharding distributes writes across partition keys.

20. A company has logs in S3 and wants SQL analysis without loading them into CloudWatch Logs. What should it use?
  1. CloudWatch Logs Insights directly on S3
  2. Athena with Glue Data Catalog
  3. Shield Advanced
  4. SQS long polling
Answer
B. Athena queries data in S3 using table metadata from Glue. CloudWatch Logs Insights queries CloudWatch Logs data.
